# Etch A Sketch project
- This is a simple vanilla js project which simulates a classic etch-a-sketch toy.
- The user is able to resize and clear the grid.
- Additionally, the user can change or randomize the colors.
- The selected color starts at 0.5 opacity and increases by 0.1 with each successive mouseover until it reaches 1.0.
- There is also an eraser available.

PLEASE NOTE: this project has not yet been made responsive for other devices.
